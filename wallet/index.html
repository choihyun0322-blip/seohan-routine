        📱 아이폰 단축어 1분 설정
        결제 문자나 카드 알림이 오면 자동으로 가계부에 기록돼요. 서버 주소만 단축어에 붙여 넣으면 끝입니다.
        1. 단축어 앱 → 자동화 → ＋ → 메시지 (또는 앱: 카드사 앱) 선택
        2. 보낸 사람에 카드사 번호를 넣고 즉시 실행을 켜요 (iOS 17부터 확인 없이 실행)
        3. 동작 추가 → URL → 위 주소 붙여넣기
        4. URL의 콘텐츠 가져오기 → 방법 POST → 요청 본문 JSON
        5. 본문에 raw 키를 추가하고 값에 단축어 입력(문자 내용)을 넣어요
        6. 끝! 지갑 앱을 열면 문자가 자동으로 가계부에 들어와 있어요
        [KB국민] 11/20 12,500원 스타벅스 [하나] 11/20 09:22 스타벅스 5,600원 승인 { "amount": 12500, "merchant": "스타벅스", "card": "KB국민" }
        승인취소·이체 문자는 자동으로 건너뛰고, 이미 들어온 같은 내역은 두 번 기록하지 않아요.
